# Modern Todo App

A simple and interactive To-Do List web application built using **HTML,
CSS, and JavaScript**. It helps users add, complete, and delete tasks
while keeping their task list saved in the browser.

## Features

-   **Add tasks:** Enter a task and add it using the Add Task button.
-   **Keyboard support:** Press Enter to add a task.
-   **Complete tasks:** Mark a task as completed using the check button.
-   **Delete tasks:** Remove individual tasks using the delete button.
-   **Task statistics:** View the total, completed, and pending task
    counts.
-   **Clear all tasks:** Remove all saved tasks after confirmation.
-   **LocalStorage:** Tasks remain saved in the browser even after
    refreshing or reopening the page.
-   **Responsive layout:** The task cards adjust to smaller screens.

## Technologies Used

-   **HTML5** -- Structures the web page.
-   **CSS3** -- Provides the layout, colours, and styling.
-   **JavaScript** -- Handles task operations and DOM manipulation.
-   **Browser LocalStorage** -- Stores tasks locally in the browser.

## How to Run the Project

1.  Download or clone this repository.
2.  Open the project folder in Visual Studio Code or another code
    editor.
3.  Open `index.html` in a web browser.
4.  Alternatively, use the **Live Server** extension in Visual Studio
    Code and select **Open with Live Server**.

## How to Use

1.  Type a task in the input box.
2.  Click **Add Task** or press **Enter**.
3.  Click the check button to mark a task as completed.
4.  Click the delete button to remove a task.
5.  Use **Clear All Tasks** to remove every task.

## Data Storage

The application uses the browser's `localStorage` to save the task list.
This means tasks are stored in the browser on the device being used.
They are not automatically synced to other devices or browsers.
